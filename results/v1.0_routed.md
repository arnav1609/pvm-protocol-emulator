# PVM v1.0 routed build and four-variant comparison

## Build provenance

The full variant checked out source commit
`752ebb97824cfd1161581497c22d3c171c4c6ca9`. The checked-out
`src/` and `info.yaml` matched the `rtl-freeze` commit
`b33a9227ac187f791a3733b94ac4e32879b10414` byte for byte.
Variants A, B and C checked out the freeze commit directly. The
submission artifacts record the checked-out source SHA in
`tt_submission/commit_id.json`. GitHub Actions displays the separate
dispatch workflow SHA `03395e521a690a94342b14f0f415e02a1f1597cb`.

All four jobs used the same 8×4 footprint and 20 ns clock constraint
(50 MHz), on Ubuntu 24.04 with LibreLane 3.1.0.dev4 and the
`ihp-sg13cmos5l` PDK at
`89d42ee6d2fd9b50b86a1aada6fee6673c3e6008`. The support
tools were pinned to `0922544e6c7f6126047c3fba720b0437fa32a1b8`
and the GDS action was pinned to
`e7a50f8f46f9f8df4b2c9935bfeb1cbc6b6ae4f6`.
Resolved configurations agree apart from the variant defines.

## Full-variant release checks

Variant D's GDS and gate-level host/pin-safety smoke passed.
The exact-commit Tiny Tapeout precheck passed all ten checks and
reported zero findings in the three DRC XML reports.
[Precheck job](https://github.com/arnav1609/pvm-protocol-emulator/actions/runs/45050926472/job/137321125339) · [Precheck artifact](https://github.com/arnav1609/pvm-protocol-emulator/actions/runs/45050926472/artifacts/14770978772) · [Case summary](../evidence/v1.0_rc/physical/precheck_summary.json)

The routed netlist has SHA-256
`e7f061e6bbaab1f222dd3fd3f4925da9fcf3625588f4aaf6cabbe7cd1f9f17e7`.
The replay script verified this hash before running the four
functional gate replays. UART, SPI and I²C passed their pin checks.
Both initial and reloaded DMX512 P5 captures matched the accepted
RTL waveform cycle for cycle. Icarus 13.0 used the pinned PDK
functional models. The package supplies SDF at all three corners
for follow-up delay-annotated simulation.

Compared to the owner-reviewed frozen physical build, the new OAS and
netlist match byte for byte and the reported area and timing match.
The GDS difference is confined to 58 library and structure timestamp
records.
